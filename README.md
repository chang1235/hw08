## 三組測試結果摘要
- **測試一（原始資料：4 人、折價券 100 元）**：應付總額 `1220.00` 元、每人費用 `305.00` 元、是否超過預算：`True`
- **測試二（人數改為 `"5"`、折價券維持 100 元）**：應付總額 `1220.00` 元、每人費用 `244.00` 元、是否超過預算：`False`
- **測試三（人數改回 `"4"`、折價券改為 220 元）**：應付總額 `1100.00` 元、每人費用 `275.00` 元、是否超過預算：`False`

## 個人回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
`"4"` 加上引號後在 Python 中是文字（字串型別），不是可以直接拿來算數的數字。如果直接拿字串去做除法或算術運算會出錯，因此要先用 `int("4")` 轉成整數 `4`，才能正確計算每人分攤的金額。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
第一組的應付總額會變成 **`1210.00` 元**。
- 算式：先扣折價券 `1200 - 100 = 1100` 元，再算 10% 服務費 `1100 * 0.10 = 110` 元，最後總額為 `1100 + 110 = 1210` 元。
- 差異原因：因為服務費計算的基準變小了（從 `1200` 元變成 `1100` 元），所以服務費少了 `10` 元（`110` 元而不是 `120` 元），導致總額比題目規定的 `1220` 元少 `10` 元。
